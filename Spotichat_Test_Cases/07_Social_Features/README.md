# Module: Social Features

Mô-đun mang tính đặc trưng của Spotichat, kết hợp âm nhạc và tương tác xã hội.

## Các tính năng chính:
- **Chat Rooms:** Nhắn tin trong phòng chat.
- **Listening Rooms:** Nghe nhạc cùng nhau trong thời gian thực.
- **Friendships:** Tìm kiếm, gửi lời mời kết bạn, chấp nhận kết bạn.
- **Direct Messaging:** Nhắn tin riêng giữa các người dùng.

## Gợi ý Test Case:
1. **Gửi tin nhắn realtime:** User A gửi tin -> User B nhận được ngay lập tức (không cần load lại).
2. **Tạo Listening Room:** Chủ phòng phát nhạc -> Các thành viên khác nghe cùng một lúc.
3. **Kết bạn:** Gửi lời mời -> Người nhận thấy thông báo và có thể Accept/Decline.
4. **Trạng thái online:** Hiển thị đúng người dùng đang online/offline.
