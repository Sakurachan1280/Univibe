# Module: Admin Management

Mô-đun dành riêng cho quản trị viên để quản lý nội dung và hệ thống.

## Các tính năng chính (Screens):
- **Admin Dashboard:** Tổng quan hệ thống.
- **Song Management:** Thêm, sửa, xóa bài hát.
- **Album Management:** Tạo và quản lý album.
- **Artist Management:** Quản lý thông tin nghệ sĩ.
- **System Logs:** Theo dõi nhật ký hoạt động của hệ thống.

## Gợi ý Test Case:
1. **Kiểm tra quyền Admin:** Tài khoản thường không được truy cập vào các màn hình Admin.
2. **Thêm bài hát mới:** Upload file nhạc, hình ảnh, thông tin -> Bài hát hiển thị trên App.
3. **Chỉnh sửa Album:** Thay đổi tên hoặc danh sách bài hát trong album.
4. **Xóa nghệ sĩ:** Kiểm tra xem các bài hát liên quan có bị ảnh hưởng không.
5. **Xem Log:** Log mới nhất phải hiển thị đúng hành động vừa thực hiện.
